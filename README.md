# Urban-Interface-
Website and Application Design 

`web-design.html` describes the small business website service and features a project from the portfolio. Keep its canonical URL aligned with `sitemap.xml` if the page moves.

Work links directly to the project sites or demos. The main navigation links to `case-studies.html`, which lists the Peak Landscapes and Colorado Warriors Hockey case studies. Each study links back to the index and to its project site or demo.

To enable a hero video on Web Design & Development (`web-design.html`) or the Case Studies landing page (`case-studies.html`), add a short, compressed MP4 (ideally without audio) under `video/` and set `data-src="video/your-file.mp4"` on that page's hero `<video>`. Optionally set `data-mobile-src` to a smaller mobile version. Leave `data-src` empty until the clip is available. The gradient stays visible if playback is unavailable, and the video is not loaded on navigation when reduced motion or browser data saving is enabled.
