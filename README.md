# Urban-Interface-
Website and Application Design 

`web-design.html` describes the small business website service and features a project from the portfolio. Keep its canonical URL aligned with `sitemap.xml` if the page moves.

Work links directly to the project sites or demos. The main navigation links to `case-studies.html`, which lists the Peak Landscapes and Colorado Warriors Hockey case studies. Each study links back to the index and to its project site or demo.

The Case Studies landing page (`case-studies.html`) uses `video/338225 Medium.mp4` as its hero background video. To enable a hero video on Web Design & Development (`web-design.html`), add a short, compressed MP4 (ideally without audio) under `video/` and set `data-src="video/your-file.mp4"` on that page's hero `<video>`. Optionally set `data-mobile-src` to a smaller mobile version. Keep `data-src` empty on pages without an available clip. The gradient stays visible if playback is unavailable, and video playback is skipped when reduced motion or browser data saving is enabled.
