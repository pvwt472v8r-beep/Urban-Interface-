# Urban-Interface-
Website and Application Design 

`web-design.html` describes the small business website service and features a project from the portfolio. Keep its canonical URL aligned with `sitemap.xml` if the page moves.

The Work page links to the Peak Landscapes and Colorado Warriors Hockey case studies. Each case study links back to Work and to its project site or demo.

To enable the Web Design & Development hero video, add a short, compressed MP4 (ideally without audio) under `video/` and set `data-src="video/your-file.mp4"` on the hero's `<video>` in `web-design.html`. Optionally set `data-mobile-src` to a smaller mobile version. Leave `data-src` empty until the clip is available. The gradient stays visible if playback is unavailable, and the video is not loaded on navigation when reduced motion or browser data saving is enabled.
